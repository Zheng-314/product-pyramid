# Layer 1: 理想信念与产品哲学

## 1.1 理想信念

人在这个世界上会有各种思想，如果你要做好一个产品，就要先清楚自己的底层价值观，它通过影响你的品味、判断、思考、决策从而影响你做出来的产品。

一个有着想要改变世界思想的人和一个为了买到自己喜欢手办的人，做产品时的心态、决策依据和品味都有着巨大的差别，这是最底层的观念给人带来的影响。

### 人生意义的两个方向

古往今来所有伟大的哲学家、思想家、圣贤，关于人生的意义给出的答案大体分为两类：

- **第一类**：在人生的奉献、责任和使命中去寻找意义
- **第二类**：从人生的体验、自由和权利方面去寻找意义

两类没有对错之分，而是谈论哪一类**更有效**。

人生需要依托，需要一个承载。在饮食男女、感官享受上寻找意义比较浅薄，作为人生的承载有可能撑不住。在奉献和使命中去寻找人生的意义，这种人的精神面貌往往比较厚重。

### 核心信念

> 求其上者，次得其中；求其中者，次得其下；求其下者，终而不得。

做产品的第一个原则就是要有理想信念。相信自己做出来的产品会对别人产生影响，一旦有这样的信念和愿景——并且一定要是强烈的，被摧毁之后重新站起的信念，在众人唏嘘中依旧保持热情的——就具备创造伟大产品的条件。

## 1.2 产品哲学

> 只有疯狂到认为自己可以改变世界的人才能改变世界

产品设计的思想和原则，因理想信念不同而不同。大体分为两种：

### 类型一：改变世界的产品

判断标准：影响的人群规模和程度（如 Facebook、抖音、汽车）

设计原则：
1. **判断不能依赖用户，甚至完全不能依赖用户**
2. 产品的效率要远高于原来的产品
3. 人与产品的交互形式很有可能发生改变
4. 时机来源于某项新技术的突破
5. **需求不在表面，而在人类底层基因**

### 类型二：做好一个产品

做出一款大家满意的产品，解决具体需求和痛点。

没有优劣之分，而是理想信念不同从而运用不同的产品设计原则。根据不同的情况做出对应的判断才是重点。

## 1.3 思维方式

- **结构化思维**：把思想写下来，变成可调用的函数
- **复盘驱动**：每次决策后都复盘，更新自己的认知框架
- **Build in Public**：把过程公开，让反馈驱动成长

## 引导问题

1. 你做这件事的底层动力是什么？是使命驱动还是体验驱动？
2. 你希望这个产品影响多少人？影响到什么程度？
3. 如果这个产品成功了，世界会有什么不同？
4. 你的判断依据是什么？是数据验证还是直觉洞察？
